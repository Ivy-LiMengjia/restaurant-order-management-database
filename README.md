
# Restaurant Order Management Database

## Project Overview

This academic group project involved developing a relational database for a restaurant order management system using Microsoft SQL Server.

The database was designed to organise information related to customers, reservations, orders, menu items, staff, inventory, and payments.

## My Contribution

My main responsibility was designing and creating the database tables.

My work included:
- Creating 11 relational database tables using SQL.
- Defining primary keys and foreign keys to establish relationships between tables.
- Selecting appropriate data types for different attributes.
- Implementing constraints, including NOT NULL and CHECK, to support data integrity.

## Database Structure

The database contains 11 tables:

- Customer
- Tables
- Staff
- MenuCategory
- Ingredients
- MenuItems
- MenuItemsIngredients
- Reservations
- Orders
- OrderItems
- Payments

## Technologies and Skills

- Microsoft SQL Server
- SQL (T-SQL)
- Relational Database Design
- Primary and Foreign Keys
- Data Integrity Constraints

## Project Environment

The project was developed and tested in a university SQL Server environment.

The SQL script includes table definitions, data insertion statements, and sample queries. Some operations depend on a source table provided in the university database environment.
